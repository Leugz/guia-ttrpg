| Ação                         | Resumo                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Investigar**               | Interage com um ponto de interesse em busca de pistas. Pode examinar ou interagir.                           |
| ↳ **Examinar**               | Faz um teste de uma perícia para receber mais informações. Se não conseguir uma informação nova, perde **`1 PD`**. |
| ↳ **Interagir**              | Faz uma ação relacionada ao ponto de interesse.                                                              |
| **Recapitular**              | Recapitula o que já sabe para fazer um teste de Intuição e descobrir uma pista.<br> **`INTUIÇÃO (DT 10)`**                              |
| **Compartilhar**             | Compartilha o que já sabe com outra personagem, para que ela faça um teste de Intuição e descubra uma pista.<br> **`PESQUISAR (DT 10)`** |
| **Usar habilidades e itens** | Usa uma habilidade ou item.                                                                                  |
