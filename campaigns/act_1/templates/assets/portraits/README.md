# Retratos

Coloque aqui o retrato de cada personagem (PNG ou JPEG, recomendado 512×512).

Depois aponte para o arquivo no frontmatter da ficha:

```yaml
portrait: 'assets/portraits/alan.png'
```

O retrato aparece no botão de perfil no canto inferior esquerdo, e é a imagem
usada no token quando o jogador arrasta esse botão para o mapa. Fichas sem
`portrait` continuam funcionando: o token mostra as iniciais do personagem
sobre a cor do perfil.
